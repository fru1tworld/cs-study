# Jepsen 블로그 2016-2018

## ElasticSearch 발산 문제

날짜: 2016-08-16

Crate.io를 위한 연구 과정에서 Elasticsearch의 심각한 데이터 무결성 문제들이 발견되었습니다.

### 발견된 문제

발견된 문제는 다음을 포함합니다:
- 더티 읽기(dirty reads)
- 복제본 발산(replica divergence)
- 손실된 업데이트(lost updates)

이 문제들은 GitHub 이슈 #20031에 자세히 기록되어 있습니다.

## MongoDB 3.4.0-rc3

날짜: 2017-02-06

Jepsen이 MongoDB 3.4.0-rc3에 대해 수행한 신뢰성 테스트 결과입니다.

### 발견된 문제들

Jepsen은 MongoDB의 레플리케이션 프로토콜에서 설계 결함과 구현 버그를 식별했습니다. 이러한 문제들은 "다수로부터 승인된 작업의 손실"로 이어질 수 있었습니다.

### 협력 성과

- MongoDB는 Jepsen을 자신의 CI 시스템에 통합했습니다
- MongoDB는 2016년 10월에 선형화 가능 읽기(linearizable reads) 기능을 추가했습니다

## Hazelcast 3.8.3

날짜: 2017-10-05

Jepsen은 메모리 기반 데이터 그리드인 Hazelcast에서 데이터 손실과 관련된 여러 문제를 발견했습니다.

### 발견된 주요 문제

- 맵 업데이트 손실
- 원자적 참조(atomic references)가 원자성을 보장하지 않음
- ID 생성기가 중복 ID 생성
- 잠금(locks)이 배타성을 보장하지 않음
- 큐(queues)가 승인된 메시지를 손실할 수 있음

## Aerospike 3.99.0.3

날짜: 2018-03-06

Jepsen은 Aerospike와 함께 그들의 차세대 합의 시스템을 검증했습니다. 검증 결과, 프로세스 일시 중지 및 충돌로 인한 데이터 손실의 두 가지 알려진 시나리오가 확인되었습니다.

### 발견된 문제

이전에 알려지지 않은 버그가 발견되었는데, 이는 내부 RPC 프록시 메커니즘의 문제로 클라이언트가 성공적으로 적용된 업데이트를 확실한 실패로 볼 수 있게 했습니다.

### Aerospike의 대응 조치

- 발견된 버그를 수정
- 클라이언트 작업 승인 전에 노드가 디스크에 쓰도록 요구하는 옵션 추가
- 합의 시스템이 허용할 수 있는 최대 클록 스큐 확장 계획

## Dgraph 1.0.2

날짜: 2018-08-22

Jepsen은 분산 그래프 데이터베이스인 Dgraph를 분석했습니다. 분석 결과 "다수의 교착 상태(deadlocks), 충돌(crashes), 일관성 위반(consistency violations)"을 포함하여 건강한 클러스터에서도 레코드 손실 및 손상이 발생할 수 있음을 발견했습니다.

### 해결 현황

분석에 따르면 Dgraph팀은 협업 기간 동안 다수의 문제를 해결했으며, 남은 문제들에 대해 계속 작업 중입니다.

## MongoDB 3.6.4

날짜: 2018-10-22

Jepsen은 MongoDB와 협력하여 샤드된 단일 문서 일관성과 MongoDB의 새로운 인과관계 일관된 세션 지원을 탐색했습니다.

### 주요 발견사항

- 샤드 클러스터는 "단일 문서 선형성을 유지하는 것으로 나타났으며 샤드 리밸런싱 및 네트워크 분할 중에 삽입된 문서를 손실하지 않았습니다"
- 그러나 인과 세션(causal sessions)은 다수결 읽기 및 쓰기가 필요함
- 기본 일관성 수준에서 인과 세션은 주장된 순서 불변성을 보존하지 않았음

### 후속 조치

MongoDB는 이를 반영하여 문서를 업데이트했습니다.
