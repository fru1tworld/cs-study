# Jepsen 블로그 2022-2023

## Radix DLT 1.0-beta.35.1

날짜: 2022-02-04

Jepsen은 Radix DLT 분산 원장 시스템의 여러 버전(1.0-beta.35.1, 1.0.0, 1.0.1, 1.0.2)을 분석했습니다.

### 발견된 문제

분석 결과 "11가지 안전성 오류(stale reads, aborted and intermediate reads, 트랜잭션 로그에서 커밋된 트랜잭션의 부분적 또는 전체 손실 포함)"가 발견되었습니다. 추가로 트랜잭션이 무한정 멈추는(hang) 문제와 단일 노드 장애 상황에서의 성능 저하 문제도 확인되었습니다.

### 해결 현황

시스템 재설계 이후 RDX Works는 버전 1.1.0에서 모든 안전 문제와 무한 트랜잭션 문제가 해결되었다고 보고했습니다.

## Redpanda 21.10.1

날짜: 2022-04-28

Jepsen과 Redpanda는 협력하여 Redpanda 분산 큐(버전 21.10.1~21.11.2)를 분석했습니다.

### 발견된 문제점

- 총 10개 이슈 발견: 3개의 활성도(liveness) 문제와 7개의 안전성(safety) 문제
- 구체적 사례로는 "충돌(crashes), 중단된 읽기(aborted reads), 일관성 없는 오프셋(inconsistent offsets), 순환 정보 흐름(circular information flow), 손실되거나 낡은 메시지(lost or stale messages)" 포함

### 해결 현황

- Redpanda가 발견된 이슈 중 7개를 해결함
- 손실되거나 낡은 메시지 관련 문제와 1개의 충돌 사항은 여전히 조사 중
- 일부 이슈는 의도된 동작을 명확히 하는 문서화만 필요

### 추가 논점

분석에서 Kafka/Redpanda 트랜잭션 모델의 흥미로운 측면들도 논의되었습니다.

## MySQL 8.0.34

날짜: 2023-12-18

Jepsen은 Kleppmann의 MySQL 격리 수준 연구를 재검토하여 버전 8.0.34에서 예상 밖의 동작을 발견했습니다.

### 발견된 문제

MySQL의 `REPEATABLE READ` 격리 수준이 여러 문제를 드러냈습니다:
- G2-item, G-single, lost update 현상 발생
- 내부 일관성 위반
- Monotonic Atomic View를 만족하지 않음

이 격리 수준은 Adya의 Repeatable Read 정의도, 모호한 ANSI SQL 정의도 충족하지 않습니다.

### AWS RDS MySQL

추가로 AWS RDS MySQL 클러스터가 `SERIALIZABLE` 격리 수준에서도 일관되게 직렬성을 위반하는 현상이 발견되었습니다.
