# Shardcake 소개

> 원본: https://devsisters.github.io/shardcake/about/

Shardcake는 인기 게임 [쿠키런: 킹덤](https://www.cookierun-kingdom.com)을 만든 [Devsisters](https://www.devsisters.com) 팀이 개발한 프로젝트다. 원문은 2022년 3월부터 프로덕션에서 문제없이 사용해 왔다고 소개한다. 한국에서의 [채용](https://careers.devsisters.com/ko/position?occupations=%EA%B0%9C%EB%B0%9C) 안내도 함께 제공한다.

Shardcake는 [Akka Cluster Sharding](https://doc.akka.io/docs/akka/current/typed/cluster-sharding.html)을 여러 해 사용한 경험을 바탕으로 만들어졌다. 코드를 공유하지는 않지만, 일부 아이디어와 개념은 Akka에서 영감을 받았다.
